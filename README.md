# 广告宣传材料合规检查助手

用于广告宣传材料发布前初审的静态网页，基于十类内置规则检查风险。

## 功能

- 粘贴文案，或导入 TXT、Markdown、PDF、DOCX 和图片。
- 显示风险原文、规则依据、修改建议与人工处置状态。
- 生成保守修改稿并复审，导出 JSON、Markdown 和 CSV 报告。
- 内置案例和引导演示。

## 部署

仓库名称：`ad-compliance-checker`。在 GitHub Settings → Pages 中选择从 `main` 分支根目录部署。

当前目录是 Vue 应用的静态构建产物，不包含原始 Vue 源码或后端。文件解析组件通过外部 CDN 加载，审核基于确定性规则，不调用大模型。

本工具仅用于发布前初审，不替代法务或合规终审。
